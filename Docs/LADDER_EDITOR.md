# Échelle de pêche — travail ModEditor

Les cfg sont déjà écrits. Ne pas Package Mod avant l'étape 1 (le blueprint de shake manque). Ne pas recréer la canne arme, le hook, la quête `FW_FishingSession`, ni `DT_FW_FishingZones`.

Le stub `Resources/Localization/FW_Feedback_Loc_stub.cfg` n'est pas chargé par le jeu. Il sert de liste à copier.

## 1. Blueprint de l'appât des fonds

1. Content Browser → `Mods/FishableWaters/Content`.
2. Clic droit sur `BP_FW_Shake_BaitMeat` → Duplicate.
3. Nommer la copie `BP_FW_Shake_BaitDeep`.
4. Ouvrir le graphe. Sur l'appel `SetActiveBait`, si le SID est écrit en dur `FW_Bait_Meat`, le remplacer par `FW_Bait_Deep`.
5. Compile, Save.

Le cfg `FW_CamShake_BaitDeep` pointe déjà vers cet asset.

## 2. Textes

1. Ouvrir `Content/DataTables/LOC_Mod_FishableWaters`.
2. Pour chaque clé de `Resources/Localization/FW_Feedback_Loc_stub.cfg` qui n'est pas déjà dans la table, Add row. Row Name = la clé (`sid_items_...`). Remplir French et English.
3. Pour chaque `sid_items_*_name` nouveau, ajouter aussi `sid_items_*_short_name` avec le même texte.
4. Supprimer les lignes `sid_items_FW_FishingRod_Wep_*` si elles sont encore là. Ne pas les réécrire.
5. Save. Si le ModEditor propose de régénérer la Localization Database, accepter. Sinon Tools → Refresh Mod TextTool, puis resauvegarder `Autogenerated_*_LocalizationDatabase`.

`DisassemblingID` doit être le texte affiché au survol, pas le SID de quête. Paires prévues, à vérifier au survol après cette étape : `Ablette|Bleak`, `Perche|Perch`, `Grosse perche|Heavy perch`, `Brochet|Pike`, `Silure|Catfish`, `Patriarche|Patriarch`.

## 9. Blueprint session — après les tables

Sur `BP_FlishableWaters` seulement. `EndFishingSession` reste le seul endroit qui nettoie.

Profondeur, à brancher dans le tirage, pas pour armer la pêche :

1. Le lancer vers l'eau existe déjà (trace 800 cm, classe qui commence par `BP_Water_`).
2. Depuis le point d'eau touché, une trace vers le bas jusqu'au sol.
3. Profondeur en cm = Z de l'eau − Z du sol.
4. Si le sol n'est pas touché, la profondeur est inconnue : ignorer tout poisson dont `MinDepthCm` > 0.
5. Ignorer un poisson si la profondeur est sous `MinDepthCm`, ou au-dessus de `MaxDepthCm` quand `MaxDepthCm` > 0.

Âmes, sur la ligne patriarche seulement :

1. Compter `EArtifactSoul` dans l'inventaire du joueur. Possédé, pas équipé.
2. Si le compte est inférieur à `RequiredItemCount`, poids 0 pour cette ligne.
3. S'il n'y a pas de nœud de comptage dans la palette, s'arrêter et le dire. Ne pas inventer l'appel.

Mesh au bout de la ligne :

1. Ajouter un seul Static Mesh Component sur `BP_FlishableWaters`. Pas de collision, pas de physique, tick décoché, Mobility = Movable.
2. En WaitingBite, charger `LineMesh` en asynchrone dans une variable de session, pas dans la map d'espèces.
3. En Fight : poser le mesh, `LineMeshScale`, l'afficher, le placer au bout de la ligne.
4. Dans `EndFishingSession` seulement : vider le mesh, le cacher, oublier la variable.
