## Why HUD still shows `sid_items_FW_Bait_short_name`

`LOC_Mod_FishableWaters` **has** the key, but
`Content/Autogenerated_*_LocalizationDatabase.uasset` does **not**.

Game reads the Autogenerated DB. After editing the LOC DataTable you must **regenerate / resave** so the Autogenerated LocalizationDatabase picks up new rows (save LOC asset, cook/package mod, or ModEditor loc refresh — whichever you used when FWPerch first appeared in the DB).

Verify: LocDB currently only has FWPerch (+ fillet). After regen it must list `sid_items_FW_Bait_short_name`.
